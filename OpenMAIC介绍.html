01 / WHY IT MATTERS

不是生成一份 PPT，
而是生成一场学习经历。

OpenMAIC 把内容理解、教学设计、多媒体生成、实时互动和学习评价放在同一条链路里。中心产物不是一张幻灯片，而是一份可以被渲染、编辑、播放和持续修改的课程 DSL。

02 / ORCHESTRATION MAP

三套编排，
一份课程数据。

点击模块查看职责。关键不是“智能体越多越好”，而是把不同时间尺度的工作拆给合适的编排器。

01

课程生成

把主题和材料变成结构化课程：先生成大纲，再按类型生成场景。

02

课堂互动

Director 决定下一位发言者；Agent 输出讲解、讨论和动作。

03

长任务 Runtime

Agent Workbench 负责持续制作、修改、查资料、生成媒体和恢复。

生成层：输入材料 → Outline[] → Scene。程序负责路由、校验和标准化，LLM 负责内容生成。
input → outline[] / outline.type → generator / scene → stage
03 / ONE CLASSROOM ROUND

课堂里，
谁来发言？

Director 不是聊天机器人。它更像课堂主持人：读取当前上下文，选择角色，控制轮次；真正的教师、助教和同学由 Agent 负责表达。
01

刷新课堂状态

读取 messages、当前场景、白板账本、测验状态和 Agent 配置。

02

Director 做决定

选择某个 Agent、交还 USER，或者结束这一轮。

03

Agent 流式输出

文本和动作交错发送：讲解、聚光灯、激光笔、白板绘图都能实时播放。

04

前端串起下一轮

收到 SSE 后更新状态，再次请求服务端；多轮讨论是可控的串行循环。
