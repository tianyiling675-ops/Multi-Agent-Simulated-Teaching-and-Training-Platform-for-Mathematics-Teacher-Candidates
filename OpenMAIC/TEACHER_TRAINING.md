# 教师训练开发记录

依据：项目规划报告《多智能体教师训练系统开发文档 V1》，2026-10-25。本次交付聚焦备课到真人授课的课堂主流程，完整 V1 的后续范围保持不变。

## 当前流程

1. 打开 /teacher-training，新建课题或继续备课。
2. 从课题生成大纲、核对编辑后逐页生成可编辑课件；也可导入 PPTX 原页或添加空白页。“导入教案”支持 DOCX、文字型 PDF、TXT/Markdown，先预览编辑，再明确追加或替换教学过程。“导入参考文档”使用同一预览流程，仅加入备课来源，不改动教学过程。
3. 用 OpenMAIC 原编辑器编辑课件内容、调整页序，保存并确认材料版本。仅课件可以确认；仅教案可以使用白板试讲。
4. 配置 1–8 位虚拟学生的基础、表达特点和常见误解，冻结班级，进入 /teacher-training/sessions/{id}/classroom。
5. 真人教师点击开始。中间为课件或白板，下方为学生，右侧为对话；教师可以翻页、手写、输入文字/LaTeX、全班提问、点名、收回发言、暂停、继续和结束。
6. 历史入口仅查看记录。退出页面不会结束课堂；重新打开运行中的轮次必须明确恢复至暂停，再继续。未提交发言和板书有离开保护。

旧的 OpenMAIC 学习入口仍保留在 /legacy/openmaic；训练主流程不挂载原 AI 教师的讲课播放器或传统/Pi 自主讲授循环。

## 复用和权限边界

- 直接复用 @openmaic/renderer 的 SlideCanvas、@openmaic/editor 的受控画布与事务历史、@openmaic/generation 的大纲与页面生成。
- 模型接入复用 resolveModel/callLLM 和已有模型设置。课堂只允许服务端授权的当前学生生成回应；面向全班只提出举手候选，由教师点名后才产生单人回答。
- 模型调用在数据库事务之外执行。每次发言有触发事件、上下文截止序号和 speakerEpoch。暂停、继续讲解、点名换人、翻页或打断会撤销旧候选；迟到结果不能进入记录。
- 学生上下文在服务端投影，只包含已展示课件、公开事件、板书和该学生的初始画像/私有状态。未展示页面、教师备注、来源原文和私有答案不会作为课堂上下文发送。
- 视觉模型可以接收已展示页面的嵌入图片和服务器从已保存笔迹生成的图像；文字模型不得臆测图片/手写内容。图片/复杂图形理解效果尚需真实模型实测。
- 学生状态变更是模型候选，发布完回答后才接受服务端证据和版本检查；理解达成还要求明确检查事件、新例子/迁移回答证据。独立课堂响应不返回隐藏误解或动态状态标签。
- 学生文本分段发布，已发布文字才记入公共事件。可选学生朗读使用语音设置中的服务和音色，支持百炼千问 TTS；文字发布不等于已听完语音，当前不归档音频播放证据。

## 材料与生成

PPTX 原页导入使用原 importer，当前单份 8 MiB、总计最多 80 页；部分导入需明确确认并显示实际数量。导入预览需核对数学公式、图片、字体和布局。动画、任意复杂媒体对象的完整保真不作承诺。

PDF/DOCX 当前同样限制 8 MiB；PDF 至多 80 页，只提取文字与可转换表格。Word 提取正文、标题、列表和表格，不作为原版式编辑。DOC/PPT 需要先转换；TXT/Markdown 需 UTF-8，单份不超过100 KB。转换结果至多10万字符，教学过程至多3万字符；超长内容需要在预览中选取本次导入部分，不静默截断。来源材料最多5份，草稿请求总计限制32 MiB。

DOCX/PDF 由独立 Python 服务使用固定版本 MarkItDown 0.1.9 转换。只注册自定义 DOCX 适配器和 PDF 转换器，关闭内置转换器和插件。DOCX 适配器不调用默认 Word 公式预处理：原生 Office Math、内嵌对象保留待处理标记及原文档包位置，等待后续独立公式模块；图片只标出核对位置。扫描 PDF 明确提示需要 OCR，混合 PDF 显示未提取文字的页码。转换失败不能回退到默认 Word 公式转换器。

预览编辑和取消均不改动当前草稿，应用后仍需保存或确认材料版本。来源保存原始上传字节、SHA-256、转换前的原始 Markdown、转换版本与警告；参考文档经编辑的文字另存，不覆盖原始转换结果。来源列表可下载原件、查看核对提示，确认后仅从当前草稿移除来源；教学正文、课件页及历史材料版本继续保留。

开发环境转换服务默认 `http://127.0.0.1:9040`，生产需配置 DOCUMENT_CONVERTER_URL。服务启动、锁定依赖、可选内部令牌与 Docker profile 见 [document-converter/README.md](document-converter/README.md)。capabilities 的 documentConversion 基于服务健康探测。文档转换在存储事务之外执行；服务每次使用独立工作进程，限制并发、容量与超时。

材料确认冻结页面、原文件和资源字节；拒绝未归档的可变 URL/blob/mediaRef。新版本不会改写旧轮次。正文和公式 HTML 在存储边界清洗。生成任务捕获来源，允许核对修改未完成页面的大纲，逐页保存成功结果；失败/取消保留成功部分，重试不会重复追加已完成页。页面生成使用短事务租约防止重复并发；生成期间的草稿修订冲突不会覆盖用户编辑。

## 持久化与兼容

SQLite 使用 BEGIN IMMEDIATE；PostgreSQL 使用 owner 行锁。teacher_training_records 分别保存材料、草稿、班级、轮次、运行状态、单个事件、回执和按 SHA-256 寻址的嵌入资源。每次事务只更新改变的记录，避免每一笔板书重写整个课件。读取仍按 owner 装配领域快照，大规模工作区的查询分页和内存占用仍需优化。

旧 teacher_training_owners 聚合可直接读取，首次写入时在同一事务内迁移，保留所有业务 ID、版本和哈希。模型和网络操作不持有数据库锁。课堂后续读取 runtime 接口，只返回运行状态和事件，避免反复通过网络发送冻结材料和原附件。

有 DATABASE_URL 时复用现有 PostgreSQL provider；本机开发默认 data/teacher-training.sqlite。生产无 PostgreSQL 时需显式 TEACHER_TRAINING_ALLOW_LOCAL=1，并持久挂载数据目录。不会静默降级至内存。

身份仍是服务端随机设备 Cookie，HttpOnly/SameSite=Strict/HTTPS Secure，保存 30 天。owner 和关联对象均由服务端校验；清除 Cookie、跨设备登录及云端账号恢复尚未接入。

## 接口

统一 /api/teacher-training：capabilities、projects、drafts 更新/确认、class-configs、sessions、commands、events、rubrics；新增 materials/extract、projects/{id}/generate、preparations/{id}/outline（PATCH）、preparations/{id}/page、sessions/{id}/react、deliver、runtime。

创建使用 clientRequestId，课堂操作使用 clientEventId。教师写入校验 expectedRevision；先命中幂等回执，再检查修订。模型候选及发布另校验发言代次，不能绕过教师控制。历史读取不生成事件。

## 学生朗读接入百炼千问 TTS（2026-11-02）

原课堂只调用浏览器 `speechSynthesis`。现在复用已有 `POST /api/generate/tts`、千问适配器与统一语音设置，选择 Qwen TTS 后可将学生已经生成的回答合成为音频。沿用默认模型 `qwen3-tts-flash` 和默认音色 `Cherry`，可在现有设置中修改模型、音色、语速、音量和静音状态；本阶段学生共用所选音色，未新增逐学生音色绑定。

使用入口：模型与设置 → 语音合成 → Qwen TTS（阿里云百炼），填写百炼 API Key，地址保持默认，选择音色并点击测试。进入课堂后开启“学生朗读”；默认仍关闭。未配置或禁用的语音服务会引导打开语音合成设置。服务端也可通过现有 `TTS_QWEN_API_KEY` 和可选 `TTS_QWEN_BASE_URL` 配置，服务端凭据继续由服务端解析。

学生文字先按原流程发布，再播放对应句子的音频；长句拆分为至多 400 字的合成请求，等待播放结束再继续。暂停、收回发言、翻页、退出及关闭朗读会取消请求和播放并释放临时资源；迟到音频不能再次播放。TTS 接口继续向供应商传递请求取消信号。语音失败时继续显示当前已经生成的文字，不重新调用学生模型，也不自动改用另一种声音。音频为临时播放，尚无归档、历史回听或“实际听完”的评价证据；教师 ASR 转写流程不变。

验证：训练模块与 TTS 接口共 91 项测试通过；训练模块 TypeScript、改动范围 ESLint/Prettier 通过。3 条 Edge 浏览器场景经复验通过，包括原 PPTX/白板/恢复流程、学生交互，以及新增的千问请求配置、实际 WAV 解码起播、暂停后的音频停止、TTS 失败后文字继续发布和关闭朗读后迟到音频拒绝。浏览器使用受控模型响应和样例 WAV，没有调用真实百炼服务。

本机服务端尚未配置千问 TTS 凭据，真实供应商连接、音色效果、延迟及实际设备听感仍需配置凭据后试听验收；不将上述受控验证称为真实百炼验收。当前改动为本地代码，未推送或部署。本轮关键原文件备份位于 `.local-logs/tts-before-20261102`。

## 点名实时通话

开启课堂底部的「实时点名」，点一位虚拟学生后授权麦克风。连接就绪后先由教师开口。老师可以连续追问，开口插话或点击「停止当前回答」时会清空当前学生的待播音频。收回发言、换人、翻页、改动板书、暂停、结束或离开课堂都会关闭通话。每次通话最多 5 分钟。

本机在 `.env.local` 设置以下变量，在两个终端分别运行 `pnpm dev` 和 `pnpm dev:teacher-voice`。如果应用使用其他端口，请同步更新 `TEACHER_VOICE_APP_URL`。新增了 WebSocket 依赖，已有安装可运行 `pnpm install --frozen-lockfile` 更新。

```dotenv
TEACHER_VOICE_WS_URL=ws://localhost:9041/voice
TEACHER_VOICE_APP_URL=http://localhost:3000
TEACHER_VOICE_BRIDGE_SECRET=<至少32字符的随机密钥>
TEACHER_VOICE_QWEN_API_KEY=<百炼实时模型API Key>
TEACHER_VOICE_QWEN_WORKSPACE=<百炼业务空间ID>
TEACHER_VOICE_QWEN_REGION=beijing
```

Docker 本机演示使用 `docker compose --profile teacher-voice up --build`，网关端口默认只绑定宿主机回环地址。对外部署时用 HTTPS 提供页面，通过反向代理暴露 `wss://…/voice`，并把该地址设为 `TEACHER_VOICE_WS_URL`。浏览器访问麦克风需要 HTTPS 或本机安全上下文。

实时通话使用百炼 `qwen3.5-omni-flash-realtime`。麦克风音频流经语音网关传给百炼。本轮复盘保存教师最终转写、完整播完的学生回答和中断前的估算播放时长。中断片段没有精确字词对齐，历史界面展示中断时间和时长。原始音频仅用于即时通话。学生角色可在当次对话中回应老师的解释，正式学情状态仍由原训练流程依据证据更新。
## 可选表情分析和片段重练

课堂中点击「开启摄像头并分析表情」后授权摄像头。可以在开课前检查预览，仅在课堂运行且页面可见时采样。关闭摄像头、结束轮次或离开页面会释放摄像头。MediaPipe Face Landmarker 在浏览器 Worker 内处理画面。原始帧、视频、音频及人脸关键点不上传。设备身份下仅保存约 2 秒采样窗口的动作计数与可用采样数量，可在复盘中删除。

`pnpm install --frozen-lockfile` 通过 `postinstall` 生成本地 JS/WASM 静态文件。已有依赖时可运行 `pnpm prepare:teacher-face` 重新生成。`pnpm build` 也会准备这些文件。固定版本模型随 `public/teacher-face-model/` 分发，摄像头需要浏览器的安全上下文。表情摘要有独立存储，课堂事件序号、发言权和虚拟学生上下文不包含该数据。

试讲复盘将嘴角、眉部动作信号与可定位的提问、回答和教师追问关联，用于教态的面部表情观测。时间线标注文字提交或发布时点，点名实时语音使用现有语音时间估算。可主动请求所选模型根据该段动作摘要和相关发言生成复核问题及练习建议。面部动作不用于判断内心情绪或生成分数。

已结束轮次的提问或学生回答片段可发起 5 分钟重练。新轮次复用冻结材料、班级和当时的课件或板书。回答片段会重放原来的学生文字回答作为固定开场。复盘可并排比较两次发言及可用的表情证据。
